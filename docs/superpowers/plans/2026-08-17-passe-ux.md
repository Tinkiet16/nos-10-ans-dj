# Passe UX « Nos 10 ans » — Plan d'implémentation

> **Pour les agents :** SOUS-SKILL REQUIS — utiliser `superpowers:subagent-driven-development` (recommandé) ou `superpowers:executing-plans` pour exécuter ce plan lot par lot. Les étapes utilisent la syntaxe `- [ ]`.

**But :** rendre l'application fiable dans ses conditions réelles (téléphone, 4G, salle bondée, un seul soir), sans ajouter de fonctionnalité ni modifier la charte visuelle.

**Architecture :** un noyau de rendu réconcilié par clé remplace les `innerHTML = …` pilotés par `setInterval`, ce qui préserve la saisie, le focus et l'intention de tap. Un verrou d'interaction de 4 s empêche le réordonnancement sous le doigt, avec restitution en animation FLIP. Les utilitaires partagés sont extraits dans `public/commun.js`, importé par les deux pages.

**Pile technique :** HTML/CSS/JS vanilla, aucune dépendance front (hors polices Google et une copie locale de `qrcodejs`). Node ≥ 18 / Express côté serveur.

**Spec :** `docs/superpowers/specs/2026-08-17-passe-ux-design.md` — à lire avant d'exécuter quoi que ce soit.

## Contraintes globales

- **Tout en français** : interface, commentaires, logs, messages d'erreur. Logs serveur préfixés d'un emoji.
- **Aucune dépendance front ajoutée.** `qrcode.min.js` est une copie locale d'une bibliothèque MIT déjà utilisée, pas une nouvelle dépendance.
- **Charte visuelle inchangée** : couleurs (`--nuit:#15161c`, `--champagne:#e6c47e`, `--rose:#b57682`), polices (Jost, Cormorant Garamond, Great Vibes), formes, rayons. Seuls les ajustements de lisibilité listés au lot 7 modifient l'écran.
- **Jamais d'emoji comme icône d'interface** — SVG inline uniquement. Les emojis dans les *textes* (🥂, ♥, 💔) sont conservés.
- **Navigation à 2 onglets maximum** (Musique / Livre d'or). Ne pas en ajouter.
- **Cibles tactiles ≥ 44 px**, zones de sécurité iPhone respectées (`env(safe-area-inset-*)`).
- **`prefers-reduced-motion`** respecté par toute animation ajoutée.
- **Aucun secret côté client.** Toute écriture Cloudinary passe par une signature calculée serveur.
- **Aucun service worker, aucun mode hors-ligne** (écarté en spec §3).
- **Contraintes Spotify structurelles** (403 sur le contenu des playlists) : ne pas tenter de les contourner.

## Méthode de vérification

Le projet n'a pas d'infrastructure de test (spec §9). **Chaque lot se termine par l'exécution réelle de son scénario de vérification, avant le commit.** Un lot dont le scénario échoue n'est pas commité : on corrige, on rejoue.

Serveur local : `npm start` → `http://localhost:3000` (invités) et `/admin.html`. Bridage réseau et `prefers-reduced-motion` via les DevTools Chrome (onglets Network et Rendering).

**Ne jamais déclarer un lot terminé sans avoir exécuté son scénario et constaté son critère de réussite.** Si un scénario ne peut pas être exécuté (pas d'iPhone sous la main pour V10, pas de VoiceOver pour V9), le dire explicitement dans le rapport du lot plutôt que de le supposer vert.

```js
/* Utilitaires partagés entre la page invités et le pupitre des mariés.
   Aucune logique métier ici : DOM, réseau, rendu de listes. */

const $ = id => document.getElementById(id);

function esc(s){
  return String(s).replace(/[&<>"']/g, c =>
    ({'&':'&amp;','<':'&lt;','>':'&gt;','"':'&quot;',"'":'&#39;'}[c]));
}

/* ---- Toast, avec action facultative (« Réessayer », « Annuler ») ---- */
let toastMinuteur;
function toast(message, options){
  const boite = $('toast');
  const action = options && options.action;
  boite.innerHTML = '<span class="toast-texte"></span>'
    + (action ? '<button class="toast-action" type="button"></button>' : '');
  boite.querySelector('.toast-texte').textContent = message;
  if(action){
    const bouton = boite.querySelector('.toast-action');
    bouton.textContent = action;
    bouton.onclick = () => { masquerToast(); options.surAction(); };
  }
  boite.classList.add('visible');
  clearTimeout(toastMinuteur);
  toastMinuteur = setTimeout(masquerToast, action ? 6000 : 2600);
}
function masquerToast(){ $('toast').classList.remove('visible'); }

/* ---- Couche réseau ----------------------------------------------------
   api() ne lève JAMAIS pour un statut HTTP : l'appelant lit .ok et .statut.
   Elle ne lève que si la requête n'a pas abouti (réseau coupé, délai). */
let fournisseurEnTetes = () => ({});
function configurerApi(fn){ fournisseurEnTetes = fn; }

const DELAI_MS = 8000;

async function api(url, options){
  options = options || {};
  // AbortController plutôt qu'AbortSignal.timeout : compatible Safari < 16,
  // qu'on croisera forcément parmi les téléphones des invités.
  const controleur = new AbortController();
  const minuteur = setTimeout(() => controleur.abort(), DELAI_MS);
  try{
    const r = await fetch(url, {
      ...options,
      signal: controleur.signal,
      headers: {
        ...fournisseurEnTetes(),
        ...(options.body ? {'Content-Type':'application/json'} : {}),
        ...(options.headers || {}),
      },
    });
    const data = await r.json().catch(() => ({}));
    return { ok: r.ok, statut: r.status, data };
  } finally {
    clearTimeout(minuteur);
  }
}

/* ---- Sondage avec reprise automatique ---------------------------------
   Cadence normale = periodeMs. Après un échec : 2×, 4×, 8×… plafonné à 30 s.
   Retour à la cadence normale dès la première réponse valide. */
const Reseau = {
  _enEchec: new Set(),
  _surChangement: null,
  enPanne(){ return this._enEchec.size > 0; },
  surChangement(fn){ this._surChangement = fn; },
  _signaler(nom, ok){
    const avant = this.enPanne();
    if(ok) this._enEchec.delete(nom); else this._enEchec.add(nom);
    if(this._surChangement && avant !== this.enPanne()) this._surChangement(this.enPanne());
  },
};

function creerSondage(nom, action, periodeMs){
  let echecs = 0, minuteur = null, arrete = false;
  async function tour(){
    try{ await action(); echecs = 0; Reseau._signaler(nom, true); }
    catch(e){ echecs++; Reseau._signaler(nom, false); }
    if(arrete) return;
    const attente = echecs
      ? Math.min(30000, periodeMs * Math.pow(2, echecs))
      : periodeMs;
    minuteur = setTimeout(tour, attente);
  }
  tour();
  return { arreter(){ arrete = true; clearTimeout(minuteur); } };
}
```

- [ ] **Étape 1 : ajouter le réconciliateur à `commun.js`**

```js
/* ---- Rendu de liste réconcilié par clé --------------------------------
   Met à jour les nœuds EN PLACE au lieu de tout recréer : la saisie en
   cours, le focus et les animations survivent au rafraîchissement.
   Les nœuds sans data-cle (message « liste vide », etc.) sont ignorés :
   gérer ces états hors du conteneur. */
function rendreListe(conteneur, items, cle, construire, mettreAJour){
  const existants = new Map();
  for(const noeud of Array.from(conteneur.children)){
    if(noeud.dataset && noeud.dataset.cle) existants.set(noeud.dataset.cle, noeud);
  }
  const voulus = [];
  for(const item of items){
    const k = String(cle(item));
    let noeud = existants.get(k);
    if(noeud){ mettreAJour(noeud, item); existants.delete(k); }
    else { noeud = construire(item); noeud.dataset.cle = k; }
    voulus.push(noeud);
  }
  for(const orphelin of existants.values()) orphelin.remove();
  voulus.forEach((noeud, i) => {
    if(conteneur.children[i] !== noeud){
      conteneur.insertBefore(noeud, conteneur.children[i] || null);
    }
  });
}

/* ---- FLIP : anime un réordonnancement sans animer la mise en page -----
   transform/opacity uniquement. Interruptible : l'animation précédente
   est annulée, et l'état final est celui du DOM (jamais posé par une
   animation qui se terminerait). */
function flip(conteneur, muter, duree){
  duree = duree || 320;
  if(window.matchMedia('(prefers-reduced-motion: reduce)').matches){ muter(); return; }
  const avant = new Map();
  for(const n of conteneur.children) avant.set(n, n.getBoundingClientRect().top);
  muter();
  for(const n of conteneur.children){
    const depart = avant.get(n);
    if(depart === undefined) continue;            // nœud nouveau : pas de FLIP
    const ecart = depart - n.getBoundingClientRect().top;
    if(!ecart) continue;
    if(n._animFlip) n._animFlip.cancel();
    n._animFlip = n.animate(
      [{transform:'translateY(' + ecart + 'px)'}, {transform:'translateY(0)'}],
      {duration: duree, easing:'cubic-bezier(.2,.8,.2,1)'}
    );
  }
}
```

```js
/* ---- Verrou d'interaction ----------------------------------------------
   Après un tap sur un bouton de vote, l'ORDRE de la liste est figé 4 s.
   Les compteurs, eux, continuent d'être mis à jour en place : l'interface
   reste vivante, mais la carte visée ne se dérobe pas sous le doigt. */
const DUREE_GEL_MS = 4000;
let derniereFile = [], ordreGele = null, gelJusqua = 0, minuteurDegel = null;

function signatureFile(q){
  return q.map(t => t.uri+'|'+t.pour+'|'+t.contre+'|'+t.monVote).join('~');
}
let derniereSignature = null;

function gelerOrdre(){
  ordreGele = derniereFile.map(t => t.uri);
  gelJusqua = Date.now() + DUREE_GEL_MS;
}

function appliquerFile(queue){
  derniereFile = queue;
  const gele = Date.now() < gelJusqua && ordreGele;
  let aAfficher = queue;
  if(gele){
    const rang = new Map(ordreGele.map((u,i) => [u,i]));
    aAfficher = queue.filter(t => rang.has(t.uri))
                     .sort((a,b) => rang.get(a.uri) - rang.get(b.uri));
    clearTimeout(minuteurDegel);
    minuteurDegel = setTimeout(() => appliquerFile(derniereFile),
                               gelJusqua - Date.now() + 50);
  } else {
    ordreGele = null;
  }
  aAfficher.forEach((t,i) => { t._premier = (i === 0); });
  $('file-vide').style.display = aAfficher.length ? 'none' : 'block';
  $('file-vide').textContent = 'La liste est vide — à vous de jouer !';
  flip($('file'), () =>
    rendreListe($('file'), aAfficher, t => t.uri, construireCarte, majCarte));
}

async function majFile(){
  const {data:d} = await api('/api/queue');
  const queue = d.queue || [];
  const sig = signatureFile(queue);
  if(sig !== derniereSignature){
    derniereSignature = sig;
    appliquerFile(queue);
  }
  $('bandeau-pause').style.display = d.ouvert === false ? 'flex' : 'none';
  const suite = d.suite || [];
  $('zone-suite').style.display = suite.length ? 'block' : 'none';
  $('suite').innerHTML = suite.map(t =>
    '<div class="piste piste-suite">'+img(t.image)+
      '<div class="infos"><div class="t">'+esc(t.title)+'</div>'+
      '<div class="a">'+esc(t.artists)+'</div></div></div>').join('');
```

```js
/* ---- Réduction des photos avant envoi ---------------------------------
   Une photo iPhone fait ~4 Mo ; réduite, ~350 Ko. C'est la différence
   entre un envoi qui aboutit en 4G dans une salle bondée et un qui échoue.
   Tout échec de la réduction renvoie le fichier d'origine : on n'empêche
   jamais un envoi, on l'allège quand on peut. */
async function reduirePhoto(fichier, cote, qualite){
  cote = cote || 1600; qualite = qualite || 0.82;
  if(!/^image\//.test(fichier.type)) return fichier;
  let bitmap;
  try{
    bitmap = await createImageBitmap(fichier, {imageOrientation:'from-image'});
  }catch(e){ return fichier; }          // Safari ancien : on envoie l'original
  const facteur = Math.min(1, cote / Math.max(bitmap.width, bitmap.height));
  const l = Math.round(bitmap.width * facteur);
  const h = Math.round(bitmap.height * facteur);
  const toile = document.createElement('canvas');
  toile.width = l; toile.height = h;
  toile.getContext('2d').drawImage(bitmap, 0, 0, l, h);
  bitmap.close();
  const blob = await new Promise(r => toile.toBlob(r, 'image/jpeg', qualite));
  if(!blob || blob.size >= fichier.size) return fichier;   // jamais plus gros
  return new File([blob], fichier.name.replace(/\.[^.]+$/,'') + '.jpg',
                  {type:'image/jpeg'});
}
```

```js
function envoyerUnePhoto(sig, fichier, surProgres){
  return new Promise((resoudre, rejeter) => {
    const fd = new FormData();
    fd.append('file', fichier);
    fd.append('api_key', sig.api_key);
    fd.append('timestamp', sig.timestamp);
    fd.append('signature', sig.signature);
    fd.append('context', sig.context);
    fd.append('tags', sig.tags);
    const xhr = new XMLHttpRequest();
    xhr.open('POST', 'https://api.cloudinary.com/v1_1/'+sig.cloud_name+'/image/upload');
    xhr.timeout = 120000;
    xhr.upload.onprogress = e => { if(e.lengthComputable) surProgres(e.loaded / e.total); };
    xhr.onload = () => (xhr.status >= 200 && xhr.status < 300)
      ? resoudre() : rejeter(new Error('HTTP ' + xhr.status));
    xhr.onerror = () => rejeter(new Error('réseau'));
    xhr.ontimeout = () => rejeter(new Error('délai dépassé'));
    xhr.send(fd);
  });
}

/* Deux envois simultanés : plus rapide que le séquentiel, sans saturer
   le lien montant d'un téléphone en 4G. */
async function enParallele(taches, largeur){
  const file = taches.map((t,i) => [i,t]);
  const ouvriers = Array.from({length: Math.min(largeur || 2, file.length)},
    async () => { while(file.length){ const [i,t] = file.shift(); await t(i); } });
  await Promise.all(ouvriers);
}
```

```js
const Couches = {
  pile: [],
  ouvrir(nom, fermer){
    this.pile.push({nom, fermer});
    history.pushState({couche:nom}, '');
  },
  demanderFermeture(nom){
    // On passe TOUJOURS par l'historique : c'est lui qui ferme, via popstate.
    // Fermer directement désynchroniserait la pile et l'historique.
    if(this.pile.length && this.pile[this.pile.length-1].nom === nom) history.back();
  },
};

window.addEventListener('popstate', e => {
  // e.state.couche = la couche qui était au sommet à CETTE entrée d'historique.
  // Tout ce qui est empilé au-dessus doit se fermer. Une entrée sans couche
  // (changement d'onglet par le hash) ferme donc tout.
  const nom = e.state && e.state.couche;
  while(Couches.pile.length &&
        Couches.pile[Couches.pile.length-1].nom !== nom){
    Couches.pile.pop().fermer();
  }
  synchroniserOnglet();
});
```
